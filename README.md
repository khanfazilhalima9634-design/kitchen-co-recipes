# Kitchen & Co Recipe Platform

This is a working static starter built from the uploaded Kitchen & Co design, but with the demo behavior replaced by real client-side pages and persistent browser features.

## Included
- Responsive homepage
- Recipe search and category filtering
- Individual recipe pages
- Recipe JSON-LD schema
- Save recipes with localStorage
- Share button
- Print recipe
- Newsletter subscriber storage in localStorage
- Admin dashboard
- Content opportunity ranking using demo trend scores
- Pinterest / Instagram / Facebook / YouTube social caption generator
- robots.txt and sitemap.xml
- No framework/build step required

## Important: live trend data
The platform/social trend section is intentionally NOT fake. The included trend scores are demo data. To show live Pinterest, Instagram, Facebook, YouTube or Google trend metrics, connect the relevant approved APIs or import your own analytics data into a backend/database.

## Deploy
Upload the folder to GitHub Pages, Cloudflare Pages, Netlify, or another static host.

## Before launch
1. Replace YOUR-DOMAIN.example in sitemap.xml and robots.txt.
2. Replace demo recipes with your original recipes and your own food photography.
3. Add Privacy, Terms, Cookie and Affiliate Disclosure pages.
4. Connect a real email service instead of localStorage.
5. Add a backend/database if you want multi-user admin and live analytics.
6. Add your approved ad network code in the marked ad slots.
7. Configure real social links and approved API credentials server-side.

## SEO
Each recipe page includes title/description and Recipe structured data. Expand each recipe with genuinely original content, unique photos, author information, FAQs and internal links before publishing at scale.


## GitHub Pages
This build uses relative asset and page paths so it works when hosted at `/kitchen-co-recipes/` as a GitHub Pages project site.
